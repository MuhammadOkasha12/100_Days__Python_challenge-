## 📌 Overview

A dedicated repository documenting 100 consecutive days of Python programming, algorithms, data structures, automation scripts, and software engineering projects.

---

## ✨ Key Features

- 🧩 **Day 1-25**: Python Foundations, Control Flow, Functions, and OOP.
- ⚙️ **Day 26-50**: Data Structures, File I/O, Web Scraping (BeautifulSoup), and APIs.
- 🤖 **Day 51-75**: GUI Apps (Tkinter), Data Analysis (Pandas/NumPy), and Automation.
- 🚀 **Day 76-100**: Web Apps (Flask/Django), Machine Learning, and Capstone Projects.

## 🚀 Getting Started

### Prerequisites
Make sure you have the required runtime installed on your machine:
- **Git**
- **Python 3.9+ / Node.js 18+** (depending on the project)

### Quick Start

``bash
# 1. Clone the repository
git clone https://github.com/muhammadokashapak/100_Days__Python_challenge-.git

# 2. Navigate into the project directory
cd 100_Days__Python_challenge-
``
